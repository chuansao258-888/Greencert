# Mobile acceptance checklist

Use MetaMask's mobile browser with Producer, Admin and Buyer test wallets.

- [ ] At 360 px and 390 px, navigation, forms and cards fit without horizontal scrolling.
- [ ] Connect each wallet and switch to Sepolia.
- [ ] Submit evidence and a multi-unit application as Producer.
- [ ] Review evidence and approve the application as Admin.
- [ ] List, reprice and cancel a whole-batch listing as Producer.
- [ ] Buy the complete batch as Buyer and confirm its quantity stays fixed.
- [ ] Withdraw proceeds as Producer and retire the batch as Buyer.
- [ ] Refresh each page and confirm the latest chain state appears.

Record the device, browser and observed result when this is run.
